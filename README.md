# CELL-SORTING-BY-EXTRACTING-EACH-CELL-CHARACTERISTICS-USING-ARDUINO-UNO-AND-SENSORS
This project uses Arduino UNO and sensors to detect and extract characteristics of each cell, such as size and light intensity. The system processes these readings in real time to classify cells into different categories. A motor-based mechanism then automatically sorts the cells based on the extracted characteristics.
The prototype uses optical, infrared, conductivity, or size-based sensors to capture detailed information about each cell as it moves through the detection channel.
These sensors measure properties such as light absorption, reflection intensity, transparency levels, or approximate size variations. Once these sensor readings are collected, the Arduino UNO processes the data and classifies the cells according to predefined thresholds or categories.
Based on this classification, a motor-driven sorting mechanism—often implemented using servo motors or DC motors—is activated to direct each cell into the correct output path or collection chamber.
The purpose of this project is to showcase how embedded systems, basic electronics, and sensor integration can be combined to replicate the core working principles of advanced laboratory systems like flow cytometry or fluorescence-activated cell sorting (FACS). Although this model works on a simplified scale, it effectively demonstrates real-time detection, data acquisition, signal processing, and automated mechanical control.
This system offers several advantages, including affordability, modular design, and ease of customization. Additional sensors, improved calibration methods, or machine-learning-based classifiers can be integrated in the future to enhance accuracy and make the prototype suitable for more complex sorting tasks.
Overall, this project serves as an excellent academic demonstration for understanding biomedical instrumentation, automation, and embedded control. It highlights how accessible microcontroller platforms like the Arduino UNO can be used to build meaningful prototypes that bridge electronics engineering with biological analysis. The project is ideal for students, researchers, and hobbyists interested in combining EEE concepts with biomedical applications.
